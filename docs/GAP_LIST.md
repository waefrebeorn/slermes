# Slermes Desktop & Surface Parity — Fresh Gap List (2026-08-03)

> Generated by a full-project parity audit. The "no gaps" assumption was
> wrong — the desktop app contained substantial dead code and the CLI
> command surface was missing Python-registry commands. This document is the
> live gap list; items are closed as they are implemented.

## How this audit was run

- CLI surface: compared Python's authoritative `COMMAND_REGISTRY`
  (`hermes_cli/commands.py`, 84 commands) against the C dispatch table
  (`src/cli/commands.c` COMMANDS[]) and the auto-generated registry port
  (`src/cli/port_cli_command_registry.c`).
- Desktop: DA audit scripts (pass1/pass2/pass3) updated to scan the full
  modular GUI set (desktop_gui.c is a thin entry since the modular refactor).
- Dead-code scan: every exported function checked for callers.

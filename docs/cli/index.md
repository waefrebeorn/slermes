# CLI Commands — Reference

## Where the registry actually lives

The live slash-command registry is `COMMANDS[]` in **`src/hermes_cli/partial_compress.c`**
(the file name is a historical artifact; its header reads "commands.c — Slash command
definitions for Hermes C CLI"). It is the first entry of `CUPBOARD_HERMES_CLI` in
`build/objects.mk`, so it is the definition linked into the `slermes` binary.

- **110 commands** are registered (plus a NULL sentinel row). Count it yourself:
  `grep -c '{\.name="/' src/hermes_cli/partial_compress.c` → 110.
- Every entry points at a C handler with a real, non-empty body. Handler definitions were
  checked one by one against the registry (source inspection, latest run); they live mainly in
  `src/cli/cli_cmd_session.c`, `src/cli/cli_cmd_config.c`, `src/cli/cli_cmd_gateway.c`,
  `src/cli/cli_cmd_security.c`, `src/cli/cli_cmd_memory.c`,
  `src/hermes_cli/write_approval_commands.c`, `src/hermes_cli/cli_cmd_parity.c`,
  `src/hermes_cli/cli_cmd_display.c`, `src/hermes_cli/cli_cmd_mcp.c`,
  `src/hermes_cli/cli_cmd_skills.c`, and the other `cli_cmd_*` modules.
- 26 commands carry an alias; 38 are flagged `cli_only` and
  5 are flagged `gateway_only` (skipped by CLI dispatch).

Two related files that are **not** the live dispatch table:

- `src/hermes_cli/commands.c` — an older twin of the registry (96 entries; verify with
  `grep -c '{\.name="/' src/hermes_cli/commands.c`). It is not listed in any
  cupboard in `build/objects.mk`, so it is not linked into the binary.
- `src/hermes_cli/command_registry.c` — the auto-generated faithful port of Python
  `hermes_cli/commands.py:COMMAND_REGISTRY` (its header still says
  "port_cli_command_registry.c"). Its `CLI_COMMAND_REGISTRY` count is defined by
  `CLI_COMMAND_REGISTRY_COUNT` in that file; it drives the completion walk
  (`completion.py:_walk`) and `slash_exec.c`, not interactive dispatch. The path
  `src/cli/port_cli_command_registry.c` cited by older docs does not exist.

## How dispatch works

`commands_resolve()` (same file) matches case-insensitively against names and aliases, then
falls back to a unique-prefix match. `commands_dispatch()` extracts the argument string and
calls the handler; `gateway_only` commands return false in CLI mode. When dispatch fails,
`src/cli/cli.c` tries `commands_try_skill()` (slash-named skills) and then
`commands_try_quick()` (user-defined quick commands from config, executed via `popen`).
One-shot `slermes /<cmd> [args]` uses the same table.

## Honest status

Registration and dispatch are facts about the code, verified above. They are **not** proof of
behavioral parity with Python Hermes: parity is proven per-port by the oracle/watercup
suites, and the sentinel block at the top of this page (generated by `make parity` →
`scripts/run_parity_workflow.py`) is the authoritative parity accounting — do not hand-edit
it or restate its numbers elsewhere. Some handlers are deliberately print-only or depend on
POSIX facilities; the per-category pages note the ones that matter (e.g. `/image`,
`/reload-mcp`, `/restart`, `/whoami`).

# MCP Commands

## `/mcp`

Manage MCP (Model Context Protocol) servers: status, list, test.

```
/mcp [status|list|test <name>]
```

**Examples:**
```
/mcp status
/mcp list
/mcp test filesystem
```

## `/reload-mcp`

Reload MCP server configurations from config.yaml. Applies changes without restarting.

```
/reload-mcp
```

## The other two audits (different denominators)

- **Body-level reality** — `python tests/parity_reality.py`: judges bodies,
  not comments; `(void)x; return 0;` is a placeholder. This is the honest
  "how much actually works" scoreboard.
- **Port stages** — `python scripts/gen_port_stages.py` →
  [port-stages.md](port-stages.md): per-module funnel S0–S6; a module counts
  at the highest stage it fully satisfies, and S5/S6 are measured from
  actual oracle runs, never assumed.

Dated snapshots of all three with method notes:
[PARITY_LEDGER.md](../PARITY_LEDGER.md). Per-area module coverage:
`python scripts/parity_coverage.py --dirs`.

## Behavioral truth

The scanner never executes anything. Behavioral parity is proven only by:

1. the **differential oracle** — `bash tests/run_all_oracles.sh`
   (C harness vs LIVE Python over the same fixtures; any MISMATCH is a
   [FAP](fap.md)), and
2. the **watercup deep gate** — `python tests/watercup/wc_run.py`
   (trace-cup path parity; right output by the wrong path still fails).

A port is parity-closed only when BOTH say MATCH. See
[watercup-parity-oracle.md](watercup-parity-oracle.md).

## Fixes landed this audit (top-5 most-used incomplete libs)

1. **libregex** (`re`) — added `regex_findall`, `regex_split`(+maxsplit),
   `regex_replace_n` (global/count sub with dynamic sizing — old replace had a
   1024-byte expansion cap), named groups `(?P<name>..)` (`regex_group_index`,
   `regex_group_count`), `REGEX_FLAG_ICASE/MULTILINE`. Fixed: group-offset
   handling now uses real match offsets, not strstr.
2. **libdifflib** (`difflib`) — added `difflib_seq_ratio` (char-level
   Ratcliff–Obershelp matching SequenceMatcher.ratio),
   `difflib_get_close_matches` (Python tie-break semantics),
   `difflib_get_opcodes` (get_opcodes port with sorted blocks).
3. **libcsv** (`csv`) — added QUOTE_MINIMAL/ALL/NONNUMERIC/NONE modes
   (`csv_writer_set_quote_mode`, `csv_escape_field`; QUOTE_NONE errors on
   data loss like csv.Error). Documented C-side NONNUMERIC divergence.
4. **libglob** (`glob`) — component-wise matcher with FNM_PERIOD so the
   Python dotfile rule holds; `glob_escape`; `**` backtracking kept.
   Old behavior ("*" crossing "/" etc.) contradicted Python glob.
5. **libtextwrap** (`textwrap`) — added faithful `textwrap_shorten_py`
   (" [...]" placeholder, whole words dropped) and `textwrap_indent`.

Oracle caught and fixed 4 real bugs during development: named-group scan
off-by-one, unsorted opcode blocks (aliasing bug on trailing gap),
shorten buffer off-by-one/overflow (found by ASAN), close-match tie-break.

Also fixed pre-existing build blockers found by the baseline build:
gateway_runner.c missing gw_server_internals.h include; util_helpers.c
multi-char constant `'\0'` treated as -Werror.
Known remaining: tests/test_datetime.c crashes in this sandbox
(datetime_now returns garbage pointer) — pre-existing, datetime.c untouched.
